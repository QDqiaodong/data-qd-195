# 完全混合罐离散传输 v1

教学离散过程数据模型：species为1..20个唯一ASCII id；tanks为1..100个唯一id、正capacity_l、非负volume_l≤capacity及恰好所有species的非负mass_g。空罐必须各组分质量为0；非空罐浓度=mass_g/volume_l。体积单位升、质量克，不将溶质质量加到溶液体积，不模拟密度/体积变化。

steps按输入顺序处理，唯一step id；每步0..1000条transfers，id只要求步内唯一（业务身份为[step_id,transfer_id]），source/target为不同既有罐，volume_l>0。总传输≤10000，steps×tanks×species≤10^6。所有数值为有界十进制字符串，Fraction精确计算，不做浮点扣账。

同一步的全部转移同时发生，浓度全部取开步状态：传输组分质量=开步源罐质量×转移体积/开步源罐体积。先核每源总出量≤开步体积，禁止同一步用入流资助出流；再核开步-总出+总入≤容量。模型只检查开/闭步状态，不推测中途泵序或瞬态峰值。入流在闭步充分混合，下一步才按新浓度取出。同一步调整transfer列表顺序不能改变最终罐状态；两步合一步可能改变组分结果，不允许合并掩盖时序。

输出每传输体积/组分证据、每步closing和最终浓度，空罐浓度null，不假装0。每罐体积残差、全局各组分残差严格为0。无外部进料/排放、反应、沉淀、蒸发或漏损；所有罐构成封闭系统，总体积/质量守恒。输入/物理约束失败整体退出2，不发布部分前缀，调用方原数据不变。

样例第一步A→B与B→C各5L：B出流仍无盐，闭步B有50g盐/10L；第二步B→C 3L才携15g盐，最终C为15g/8L。先完成所有步骤再原子新建JSON，拒绝已有目标/链接。没有真实设备、工艺控制或持久交易账本。
